# Kept

A private personal AI that tracks the promises you make and does the work behind them. Built for the
Nebius x NVIDIA Global AI Hackathon (Personal AI track). Every model call goes to **Nebius Token
Factory** (NVIDIA Nemotron Nano, Super and Ultra).

This Space runs the **public demo**: each visitor gets a private temporary workspace with sample
promises, email is off, and usage is capped. Source and full documentation:
https://github.com/Nish459/commitment-keeper

**Open the app at its own address** (the `*.hf.space` link under "Embed this Space" in the menu), not
inside the huggingface.co page. Browsers block the session cookie in the embedded view.
